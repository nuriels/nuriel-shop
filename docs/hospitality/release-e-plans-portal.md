## E1 — פרטי העסק בהקמת חנות

**הבעיה:** בשער, אחרי שם החנות והכתובת, החנות נפתחה מיד. את פרטי העסק (ח.פ, סוג העוסק,
מע"מ, טלפון) הבעלים היו צריכים למצוא אחר כך בהגדרות, והתקנון הוצג עם מקומות חסרים.

**עכשיו:** אימייל → קוד → שם + כתובת → **פרטי העסק** → החנות נפתחת → ישר לניהול.

| שדה | חובה | נשמר ב- |
|---|---|---|
| שם העסק הרשמי | ✓ (ברירת מחדל: שם החנות) | `site_settings.business_name` |
| סוג העסק: עוסק מורשה / עוסק פטור / חברה בע"מ | ✓ | `site_settings.business_type` (חברה = מורשה; פטור → מע"מ 0%, נעול — הטריגר הקיים) |
| מספר ח.פ / ע.מ (5–12 ספרות) | ✓ | `site_settings.business_tax_id`, `tenants.tax_id` |
| המחירים באתר כוללים מע"מ / לפני מע"מ | ✓ (ברירת מחדל: כוללים; בפטור — לא מוצג) | `site_settings.prices_include_vat` |
| טלפון לשירות לקוחות | ✓ | `site_settings.support_phone` + `business_phone` |
| כתובת העסק | — | `site_settings.business_address` |
| לוגו (PNG / JPG / WebP) | — | `branding/<tenant>/site/logo-…`, `site_settings.logo_path` |
| אימייל העסק | אוטומטי — האימייל המאומת של הבעלים | `site_settings.business_email` |

**התקנון ושאר המקומות** מתמלאים מאותם שדות (`legal-content.ts` — `{{store_name}}`,
`{{business_id}}`, `{{store_phone}}`, `{{store_email}}`, `{{store_address}}`), וגם המסמכים
והמיילים. אחרי ההקמה אין "חסר" ברשימת ההתאמה לחוק, חוץ מכתובת אם לא מולאה.

**מיגרציה:** `20261104090000_portal_business_details.sql`
- `portal_create_store_business(_email, _name, _slug, _business)` — קוראת ל-`portal_create_store`
  הקיימת (אותם כללים: חשבון, מגבלת 10 חנויות, כתובת, בעלים), ובאותה טרנזקציה שומרת את
  הפרטים. קלט לא תקין → שום חנות לא נפתחת.
- `portal_set_store_logo(_email, _tenant, _path)` — רק לחנות שהאימייל מנהל, ורק לנתיב
  `<tenant>/site/logo-<מספר>.png|jpg|webp`.
- שתיהן לשרת בלבד (`service_role`). `portal_create_store` לא השתנתה — לשונית ישנה של השער
  ממשיכה לעבוד.
- **Rollback:** `supabase/rollbacks/20261104090000_portal_business_details.down.sql` — מוחק רק
  את שתי הפונקציות. הפרטים שכבר נשמרו נשארים בהגדרות.

**השרת** (`portal.functions.ts`):
- `createPortalStore` מקבל גם `business`, ובודק אותו לפני המסד.
- `uploadPortalStoreLogo` (FormData): הרשאה לפי האימייל המאומת, סוג הקובץ לפי התוכן (לא לפי
  הדפדפן), עד 2MB, ואז נשמר. כשל בלוגו לא מפיל את הפתיחה — הודעה שאפשר להעלות בהגדרות.

**בדיקות:**
- מסד: `scripts/db-tests/portal-business-details.test.sql` — 27 בדיקות: הרשאות, כל שדה לא
  תקין, אף חנות לא נפתחת בקלט שגוי, מורשה / פטור / חברה, הכללים של הפתיחה הרגילה, לוגו
  (בעלים / חשבון אחר / נתיב של חנות אחרת / `../`).
- יחידה: `tests/unit/portal-business.test.ts` — הניקוי והבדיקות (אותם כללים כמו במסד).

## E3 — חבילות לצימרים: מחירים, דמי הקמה, פירוט והגבלות

| | בסיסית | פרימיום |
|---|---|---|
| מחיר | 200 ₪ לחודש | 400 ₪ לחודש |
| דמי הקמה (חד-פעמי) | 2,000 ₪ | 2,000 ₪ |
| יחידות | עד 3 | ללא הגבלה |
| מתחמים | 1 | ללא הגבלה |
| תמונות וסרטונים לגלריה | עד 20 | עד 60 |
| מנהלים (כולל הבעלים) | 1 | 6 (הבעלים + 5) |
| סנכרון Airbnb / Booking.com (ייבוא + קישור ייצוא) | — | ✓ |
| סוגי חדרים (מצב מלון) | — | ✓ |
| קופונים ומבצעים | — | ✓ |

- **ניסיון (ההקמה)** — 14 יום, 20 יחידות, הכול פתוח; לא מפורסם.
- **"מקצועית" / "ללא הגבלה"** — החבילות הזמניות הקודמות: לא מפורסמות, הכול פתוח (אתר שכבר
  עליהן לא מאבד כלום).
- **שירות** (לא נאכף בקוד, מופיע ברשימת התכונות): תמיכה מועדפת בפרימיום, עד שעת עדכוני
  תוכן בחודש, דוח גוגל חודשי.

**האכיפה — במסד** (טריגרים לפני הוספה: כל מסלול, גם בקשות מקבילות):
- **מתחמים:** הוספה / הוצאה מארכיון. מתחם בארכיון לא נספר.
- **תמונות לגלריה:** כל גלריה נספרת לבד — האתר, כל מתחם, כל יחידה.
- **סגור בבסיסית:** יומן חיצוני, קישור הייצוא, סוג חדר, מבצע.
- **ירידה בחבילה לא מוחקת כלום.** מה שקיים נשאר ועובד (גם יומן שכבר מחובר ממשיך להסתנכרן),
  ורק לא מוסיפים.
- **אתר שאינו אתר אירוח:** המגבלות לא חלות עליו. השומרים של סוג האתר מחליטים.

**הפאנל** ("ניהול Hospitality"):
- **"חבילות ומחירים לצימרים":** כרטיס לכל חבילה, ועריכה של שם, משפט, מחיר, דמי הקמה,
  מגבלות, מה פתוח, רשימת התכונות ופרסום. כל שינוי נרשם ביומן הפלטפורמה.
- **בחירת חבילה** (בפתיחת עסק ובכרטיס העסק): עם המחיר ("בסיסית — 200 ₪ לחודש").

**אזור הניהול של העסק:**
- **"החבילה שלי"** בלוח הבקרה: מתחמים, תמונות לגלריה ומה כלול.
- **"ערוצי הזמנה" ו"סוגי חדרים"** — בחבילה בלי התכונה:
  - הודעה "זמין בחבילת פרימיום" במקום כפתורי ההוספה;
  - מה שכבר קיים מוצג.
- **מנהל משנה** (שלא רואה את פרטי החבילה) — המסד מחליט, עם אותה הודעה.

**מיגרציה:** `20261104100000_hosp_plans_pricing.sql`
- עמודות ב-`plans`: `setup_fee`, `tagline`, `highlights`, `max_properties`, `max_media`.
- הערכים של החבילות נכתבים רק אם עוד לא הוגדרו (מחיר ריק), כך שעריכה מהפאנל לא נדרסת.
- `entitlements()` מחזירה גם `max_properties`, `properties_used`, `max_media`.
- `admin_save_plan` — מנהל הפלטפורמה בלבד.
- `public_plans()` — השרת בלבד (לשער).
- **Rollback:** `supabase/rollbacks/20261104100000_hosp_plans_pricing.down.sql`
  - מסרב כשיש אתר על "פרימיום";
  - אחרת מחזיר את הכול למצב של מיגרציות 5, 7 ו-15.

**בדיקות:**
