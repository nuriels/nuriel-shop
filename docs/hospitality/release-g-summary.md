## מה נבנה

### E4 — מערכת תמיכה לעסקי האירוח (מיגרציה 33)
- **העסק (`/manage/support`):**
  - רשימה עם לשוניות;
  - זמן תגובה לפי החבילה;
  - וואטסאפ לפרימיום;
  - פנייה חדשה עם קבצים (JPEG / PNG / WebP / PDF עד 5MB);
  - שרשור, תגובה, סגירה / פתיחה מחדש;
  - תג "תשובות חדשות" בניווט.
- **הפלטפורמה (`/platform/hospitality#support`):**
  - כל הפניות, עם סינון לפי סטטוס, דחיפות, תאריכים, חיפוש ו"ממתין לתשובה";
  - תשובה או הערה פנימית, עם קבצים;
  - סטטוסים: חדשה → בטיפול → ממתינה לעסק → נפתרה → סגורה.
- **פרטיות:**
  - הערות פנימיות וקבצים שלהן לא מגיעים לעסק אף פעם;
  - צוות הפלטפורמה מוצג לעסק כ"צוות התמיכה";
  - קבצים בדלי פרטי, נבדקים לפי התוכן (גם PDF בלי JavaScript), וקישור הורדה חתום ל-2 דקות.

### E5 — sitemap, robots וגוגל
- `/sitemap.xml` לכל אתר — רק כשהאתר פתוח:
  - דף הבית, היחידות וסוגי החדרים, ושום עמוד פרטי;
  - כתובות קנוניות, ותאריך עדכון של הגרסה המפורסמת.
- `robots.txt` עם שורת Sitemap.
- לשונית "גוגל ושיתוף" בעורך:
  - כותרת ותיאור (עם מונים), תמונת שיתוף;
  - כתובת קנונית: הדומיין של העסק או כתובת הפלטפורמה;
  - קוד אימות Search Console — רק התווים המותרים נשמרים.
- ההגדרות במסמך האתר, ולכן מתפרסמות רק עם הפרסום.

### Calendar Pro
