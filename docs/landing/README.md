# דף הנחיתה של נוריאל מחשבים — nuriel-app2.nuri1.fit

עמוד הבית של אתר השער (החנות `nuriel-app2`) הוא דף הנחיתה של נוריאל מחשבים. בכל חנות אחרת עמוד הבית
נשאר הקטלוג, בדיוק כמו קודם.

שתי תקופות הניסיון נפרדות: 14 יום — רק לחנות אינטרנטית (כפתור "התחילו 14 ימי ניסיון בחינם"),

## SEO ונגישות ל-AI

- **SSR מלא לשער:** ה-HTML הראשוני כולל את כל הדף (≈9,000 תווי טקסט, H1 אחד, 7 H2, 20 H3, 8
  תמונות עם alt). לפני: 18 תווים, בלי H1.
- **head:** כותרת ותיאור קבועים לדף, `canonical` לכתובת הרשמית, Open Graph, `robots: index, follow,
max-image-preview:large`.
- **JSON-LD:** `ComputerStore` (העסק, כתובת וטלפון אמיתיים), `WebSite`, שני `Service` עם `Offer` מהמסד,
  `FAQPage` זהה לשאלות שבדף. בלי דירוגים, ביקורות, שעות או מיקום — אין לנו נתונים מאומתים. (גוגל לא
  מציג תוצאות FAQ מורחבות לאתרים מסחריים — הסימון תקני ומשמש להבנת הדף.)
- **robots.txt / sitemap:** כמו בכל חנות — מאפשר הכול חוץ מאזורים פרטיים; מפת האתר — דף הבית.
- **llms.txt** (לשער בלבד): תקציר ציבורי — שלושת התחומים, מחירים וימי ניסיון מהמסד, דוגמאות, יצירת
  קשר. תועלת מוגבלת (אין התחייבות של מנועים לקרוא אותו), עלות אפסית.
- **פרטיות:** רק תוכן ציבורי. אין קישורים לאזורי ניהול, אין נתוני לקוחות/הזמנות/כספים/מפתחות.
  צילומי מסכי הניהול — מנתוני הדגמה (`@demo.test`) בלבד.

**אבחנה:** בחנויות (מנוע ה-Ecommerce) עמוד הבית, הקטגוריות, עמודי המוצר והאודות מרונדרים בדפדפן בלבד
(`ssr: "data-only"` / ללא SSR לגוף) — גוגל מרנדר JavaScript בגל שני, אבל רוב סורקי ה-AI לא מריצים
JavaScript ורואים רק כותרת ו-JSON-LD. באתר Hospitality — הכול מהשרת.

**המלצות (לא בוצעו — מחוץ לגבולות המשימה, דורשות אישור):**

1. nuriel-shop / כל החנויות: SSR לגוף עמודי המוצר והקטגוריה (לפחות שם, מחיר, תיאור ותמונה) — שינוי
   במנוע ה-Ecommerce.
2. כותרות אבטחה לחנויות (כמו ב-Hospitality: HSTS, CSP בסיסי, nosniff, X-Frame-Options) — בשרת או
   ב-nginx.
3. nofi-dorit: הפניה קבועה (301/308) מ-`/` ל-`/stay`, ו-JSON-LD לעמודי היחידות.
4. nuriel-shop: להדליק llms.txt בהגדרות החנות (שיווק ואינטגרציות), אם רוצים.
5. לתקן בהגדרות nuriel-app2 את שגיאת הכתיב בכותרת ("איטרנטית") — בדף הבית היא כבר לא מוצגת (הדף
   מגדיר כותרת משלו), אבל עדיין מופיעה בעמודים אחרים של השער (תנאי שימוש, פרטיות).
