## הפקודה

רק אחרי אישור. את `<commit>` מחליפים במזהה מהדוח הסופי:

```bash
cd /root/nuriel-shop-git && git fetch -q origin +refs/heads/release/next:refs/remotes/origin/release/next && bash <(git show <commit>:deploy/release-next.sh) --deploy <commit>
```

אפשר להריץ קודם בדיקה מקדימה בלבד (קריאה בלבד, לא משנה כלום). זה לא חובה, כי `--deploy` מריץ את אותן בדיקות
קודם ועוצר אם משהו לא תקין:

```bash
cd /root/nuriel-shop-git && git fetch -q origin +refs/heads/release/next:refs/remotes/origin/release/next && bash <(git show <commit>:deploy/release-next.sh) --check <commit>
```
