## 1. Summary

| Severity | Count |
|---|---|
| Critical | 0 |
| High | 3 |

The plan is careful about the owner's hard limits: nothing in it runs a migration, touches production, issues a real charge or creates a SmartBee dependency without an explicit approval point, and most code/DB facts it cites are correct (section 3). The serious problems are consistency and testability:

1. **The DDL breaks an existing security test that the plan promises will pass unchanged** (H1). `billing-agreements.test.sql:116-121` pins exactly 14 `my_billing_*`/`platform_billing_*` functions, all executable by `authenticated`; the DDL adds six more, four of them `service_role`-only. "Fixing" the test by granting `authenticated` would let any signed-in user call `platform_billing_terminal_save(_actor := <admin id>, …)` and replace NURIEL's terminal credentials.
2. **The "no invoices" control is contradicted across the documents and has no implementation** (H2). The plan stops on a non-empty `Hesh`. The DEMO-blocking test NEW-U-NODOC says to ignore `Hesh` and never store it. The DDL has no parameter, column or review reason for it.
3. **The cross-terminal replay risk is understated, and the production fallback covers only one side** (H3). Anyone holding any Hyp terminal could attempt it, including a holder of a **test** terminal paying with the published test card at no cost. The plan says the same attack works store-to-store, yet its "mark for review" fallback covers only platform payments. The test meant to settle the question (M14ב) is not executable as written (M2).

Other Medium items: the plan's claim that "no existing test list changes" is wrong; codes 600/700/800 and the `billing.manage` payer rule differ between the plan and the DDL; the test catalogue is split across four files with colliding IDs; a fresh DEMO database can be flipped to `production`; the M15 tamper run collides with the VERIFY cap; "paid but never returned" has no scenario; the installments rules conflict; and the step-up control for the platform terminal is not designed.
