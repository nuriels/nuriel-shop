# זהות החנות (StoreIdentity) — שלב 1

מקור אחד לשם של כל חנות: `src/lib/store-identity.ts` (`storeNames`). פונקציה
טהורה — אותה פונקציה בשרת ובדפדפן, תמיד עם `site_settings` של החנות הנוכחית
(השרת קורא דרך `supabaseAdmin`, שמסנן כל שאילתה לפי ה-tenant).

## הכללים (החלטות בעל המערכת)

| שדה | מקור | משמש ל- |
|---|---|---|
| `name` | `business_name` ← `site_title` ← "החנות שלי" | title, og:title / og:site_name, description כשאין תיאור, WebSite / Organization.name, seller, פירורי לחם, H1, כותרות עמודים ("אודות \| שם"), llms.txt, עמודי זאפ, שם השולח במייל, מסמכים, הסכם, © בפוטר |
| `displayName` | `site_title` ← `business_name` ← "החנות שלי" | הכותרת הגלויה באתר (כמו קודם), מסך תחזוקה, טקסט ברירת המחדל באודות |
| `alternateName` | `site_title` כשיש גם `business_name` והם שונים | WebSite / Organization.alternateName |
| `ownName` | `business_name` ← `site_title`, אחרת `null` | מקומות עם טקסט משלהם כשאין שם: `{{store_name}}` בעמודים המשפטיים ("[שם העסק]"), הסכמה לדיוור, תוויות, תשלום |

- `business_name` = "שם העסק הרשמי" (הגדרות האתר ← פרטי העסק) — המקור הראשי.
- `site_title` = "כותרת האתר (שם החנות)" (עיצוב דף הבית) — שם התצוגה.
- שניהם ריקים → "החנות שלי" (ניטרלי). לא שם החנות מטבלת `tenants`, לא שם
  הפלטפורמה ולא שם של לקוח קודם.
- "סוכנות המשקאות" — ברירת המחדל הישנה של העמודה `site_title` (מיגרציה
  `20260907120000_b2b_beverage_platform.sql`) — לא נחשבת שם: עוברים למקור הבא.
  שום ערך במסד לא משתנה. `business_name` עם אותו טקסט כן נחשב (שם שבעל החנות בחר).
- Product Schema: בלי `brand` (אין למוצרים שדה מותג יצרן); `seller` = שם החנות.

## מה לא נכלל בשלב 1 (שלבים הבאים, באישור)

- favicon / לוגו ברירת מחדל של הפלטפורמה בחנויות, וקרדיט הפוטר ("מופעל על ידי
  נוריאל מחשבים" ← nuriel-app2.nuri1.fit, nofollow) — שלב 2.
- ברירות המחדל במסד (`site_title`, `sells_alcohol`), טיוטת התקנון הניטרלית,
  שם מפעיל הפלטפורמה במדיניות הפרטיות כהגדרה מרכזית — שלב 3.
- ניסוח "לקוחות עסקיים" בכניסה ובהרשמה — לא משתנה כרגע.
